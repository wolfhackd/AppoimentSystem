# Sistema de Agendamentos

## Objetivo
Desenvolver um programa cuja função principal seja a agendar serviços para clientes e conseguir gerenciar esses agendamentos e serviços.

---
# Usuários do Sistema
- Administrador
- Cliente

---
## Problemas Identificados
- Demora no agendamento de serviços
- Dificuldade em gerenciar agendamentos e serviços
- Não há uma forma eficiente de comunicar com os clientes 
- Não há uma forma eficiente de verificar se existem vagas no horário
- Não há uma forma eficiente de gerenciar os clientes

---
## Requisitos Funcionais

- RF01 -- Agendamento de horário
- RF02 -- Gerenciamento de agendamentos
- RF03 -- Comunicação com os clientes
- RF04 -- Verificação de vagas no horário 
- RF05 -- Exclusão de agendamentos 

## Requisitos Não Funcionais

- RNF01 -- Deve funcionar em dispositivos móveis
- RNF02 -- Deve ser fácil de usar e compreensível
- RNF03 -- Deve ser confiável e estável
- RNF04 -- Deve ser escalável e flexível
- RNF05 -- Apenas usuários autorizados podem modificar o estabelecimento

## Regras de Negócio

- RN01 -- Os clientes devem informar todos os dados para concluir o agendamento
- RN02 -- Os clientes devem informar o horário desejado para agendamento
- RN03 -- Os clientes devem informar o serviço desejado para agendamento
- RN04 -- Os clientes devem escolher um horário livre
- RN05 -- Não posso agendar duas vezes no mesmo horário
- RN06 -- Os clientes devem informar a data do serviço
- RN07 -- O dono deve confirmar o agendamento antes de iniciar o serviço
- RN08 -- Os clientes devem ser notificados do agendamento antes de iniciar o serviço
- RN09 -- Os clientes podem visualizar seus agendamentos e serviços
